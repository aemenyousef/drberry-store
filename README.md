# متجر د. بيري الطبي التجميلي | Dr. Berry Store

متجر إلكتروني فاخر لمنتجات العناية بالبشرة والشعر ومستحضرات التجميل الطبية (Next.js 16 + React 19 + Tailwind CSS 4).

## 🌟 مميزات المتجر
- **واجهة عصرية وسريعة:** مبنية بأحدث إصدارات Next.js 16 (App Router) و React 19.
- **تعدد اللغات (i18n):** دعم كامل للغة العربية (افتراضي RTL) واللغة الإنجليزية عبر `next-intl`.
- **نظام العملات المتعددة:** دعم الريال السعودي (SAR)، الريال اليمني (YER بسعرين)، والدولار الأمريكي (USD).
- **إتمام الطلبات عبر الواتساب (WhatsApp Checkout):** رسائل طلب ذكية ومختصرة مرتبطة مباشرة بخدمة العملاء ومتابعة الإيصالات.
- **الشراء السريع (Express Checkout):** تجربة شراء بنقرة واحدة بدون تعقيد.
- **قاعدة بيانات سحابية:** اتصال مع Supabase لمزامنة وتخزين الطلبات سحابياً.

---

## 🚀 طريقة التشغيل المحلي (Development)

1. الدخول لمجلد المشروع:
```bash
cd drberry-store
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```

3. فتح المتجر في المتصفح:
[http://localhost:3000](http://localhost:3000)

---

## 📦 بناء الإنتاج (Production Build)

```bash
npm run build
npm run start
```
